# Notas de repaso

Estas notas reúnen las herramientas matemáticas que usa el curso. **No hay
que leerlas de corrido**: la tabla de abajo dice qué repasar antes de cada
bloque.

## Cómo están organizadas

Cada área tiene tres niveles:

| Nivel | Para qué sirve |
|---|---|
| **Básico (B)** | Lo que se supone sabido al empezar el curso |
| **Intermedio (I)** | Lo necesario para seguir las clases, las tareas y las notas formales |
| **Avanzado (A)** | Lo necesario para los puntos **[Avanzado]**: demostraciones y extensiones |

Cada concepto tiene una clave: **área.nivel + número**. Por ejemplo, la clave
**D.I2** es el segundo concepto intermedio de ecuaciones diferenciales. Las
claves son enlaces: llevan directamente al concepto. Cada área termina con un
**autodiagnóstico** con respuestas.

| Clave | Área | Archivo |
|---|---|---|
| **C** | Cálculo de una y varias variables | `calculo.md` (pendiente) |
| **L** | Álgebra lineal | `algebra_lineal.md` (pendiente) |
| **D** | Ecuaciones diferenciales y en diferencias | `ecuaciones_dinamicas.md` (pendiente) |
| **A** | Análisis: sucesiones, convergencia, conjuntos y puntos fijos | `analisis.md` (pendiente) |
| **N** | Métodos numéricos | `metodos_numericos.md` (pendiente) |
